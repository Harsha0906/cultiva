# Step 10.2: Retro sound effects

## Sounds (generated in code, owned by Cultiva, as decided)
`tools/audio/make_sfx.py` writes 16-bit mono 22 kHz WAVs to `app/assets/sfx/`. Each is short, soft, and has a fade-in and fade-out so it never clicks.

| File | Used for | Recipe |
|---|---|---|
| `plant.wav` | Planting a task | A low square "pop" with a falling pitch (120 ms) |
| `ripen.wav` | Completing a check task / ripening | Two rising notes (180 ms) |
| `harvest.wav` | Harvest | A plucked note plus a bright chime (300 ms) |
| `coin.wav` | Coins landing in the pill / welcome gift | The classic two-tone ding (B5 → E6, 220 ms) |
| `done.wav` | Focus timer finished | A rising C-E-G-C arpeggio (450 ms) |
| `buy.wav` | Shop purchase | A soft cash-register style blip (200 ms) |

## Playback
- **Package:** `audioplayers`, a small cross-platform dependency, added deliberately for v1 sound.
- **`core/sfx.dart`:** `Sfx.play(SfxName)` uses a small player pool with low-latency mode.
  - It's skipped when **Sound** is off in Settings.
  - Playback errors are caught and ignored, so sound is never allowed to crash the app.
  - Sounds play alongside other audio (music apps keep playing) and the volume stays gentle.
- **Wired into:** plant (sheet success), ripen (Plot B done), harvest (farm, Tasks and Focus), coin (CoinFly landing and welcome gift), done (focus finishes in-app), and buy (shop).

## Verification
- **Unit test:** `Sfx` doesn't play when the sound pref is off. The player is injected, so tests never touch the platform.
- **By ear on the emulator:** plant, harvest and the coin landing.
