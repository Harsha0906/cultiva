# Step 4.3: Live header, "Next up" & barn badge

## Design
- **Header:**
  - Avatar from Settings, tapping to Profile.
  - Pill with the **live coin balance** and `done/due today`.
  - Calendar showing today's farm date.
- **Next up button:** a full-width terracotta `PixelButton` just above the nav, within thumb reach. It's the screen's one primary action.
  - **Which task:** the first unfinished *due* task. Plot A goes before Plot B, then dormant first (bring it back), then by slot.
  - **Label:** `Next up: Read · 30 min` (timed) or `Next up: Pay bill` (check).
  - **Action:** Plot A opens Focus Mode; Plot B completes the task.
  - **If everything is done:** `Everything's harvested!` (quiet paper style, disabled).
  - **If nothing is planted:** `Plant your first task` (opens planting).
- **Barn badge:** a terracotta dot with today's harvest count. Tapping the barn shows the storage message (full Storage arrives in Phase 7).
- **Home tap:** the capybara greets the player (see 4.4).

## Verification
Unit tests for `nextUp()` ordering, plus a widget test for the button label states.
