# Step 5.1: "Plant a task" sheet

## Goal
Players can plant tasks themselves from the farm and the Tasks tab, with no debug seeding needed.

## Opened from
- Tapping empty soil (plot preselected, slot = that free slot's plot).
- The "Plant your first task" button.
- The Tasks tab's **Plant** button.
- Each plot header in the Tasks tab.

## Form (paper sheet, top to bottom)
1. **Task name:** a labelled text field, required, 1–40 characters, sentence capitalisation, keyboard action "Done".
2. **Plot toggle:** **Daily (timer)** or **To-do / Habit**. It shows `x/6` per plot, and a full plot is disabled with the reason "Plot full".
3. **If Daily:**
   - **Duration:** chips for 5 / 15 / 30 / 45 / 60 min, plus **Custom** (a number field, 1–240).
   - **Repeat:** 7 day toggles M T W T F S S, all selected by default. At least one is required.
4. **If To-do / Habit:**
   - **Type:** **To-do (once)** or **Habit (repeats)**.
   - Habits show the day toggles.
5. **Crop:** a grid of the 9 crops, each drawn at its ripe stage. The selection gets a teal border plus a check mark, so colour isn't the only signal. It's cosmetic, with a random default.
6. **Plant it:** the primary terracotta button.

## Behaviour
- **Validation runs on submit:**
  - Errors appear below their field (e.g. "Give the task a name.", "Pick at least one day.").
  - Focus moves to the name field when it's missing.
  - The rules come from `FarmTask.problems`, so the form and the database agree.
- **Submission guard:** set *synchronously* before the first `await`. Repeated taps start only one plant, and the button shows "Working…".
- **On failure** (e.g. the plot filled up meanwhile): the input is kept, the error shows above the button, and the player can retry.
- **On success:** the sheet closes, a message says "Read planted in Daily", and a light haptic plays.
- Every async callback checks `mounted`, so nothing runs after the sheet is gone.

## Files
`app/lib/features/tasks/plant_task_sheet.dart`, `app/lib/core/ui/crop_sprite.dart` (shared crop thumbnail), `app/lib/domain/crops.dart` (crop list and frame heights)

## Verification
Widget tests on an in-memory database:
- an empty name shows an error and plants nothing
- Daily with no days shows an error
- a valid Daily plants with the right minutes and days
- a to-do and a habit plant correctly
- a double tap plants exactly one task
- a full plot shows its reason and keeps the input

flutter-ui-patterns (forms), flutter-accessibility
