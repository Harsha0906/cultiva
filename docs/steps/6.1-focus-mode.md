# Step 6.1: Focus Mode

## Goal
Daily (timed) plants grow while the player focuses, and ripen when the timer ends.

## Timer model (timestamp-based, never a ticking counter)
- **One `focus_sessions` row per task per farm day** (the table already exists, so the schema doesn't change):
  - `accumulatedSec` holds finished segments.
  - `startedAt` is when the *current* running segment began.
  - `status` is `running`, `paused`, `abandoned` or `done`.
- **Elapsed** = `accumulatedSec` + (running ? `now − startedAt` : 0). It's computed whenever needed, so the timer survives the app being closed, killed or backgrounded.
- **Planned** = target minutes × 60. Finishing at elapsed ≥ planned ripens the plant: `FarmService.complete(method: focus)`.

## Clock-change guard (gentle: Cultiva is a self-improvement app, not a casino)
- **Clock moved backwards** (`now < startedAt`): the segment counts as 0, `startedAt` resets to now, and the session is flagged `suspicious`.
- **Clock jumped far forward** (one segment longer than planned + 2 h): it's capped at planned and flagged `suspicious`.
- **While the screen is open**, a monotonic `Stopwatch` is checked against wall time every tick. A drift of more than 90 s flags the session.
- **A suspicious session still ripens**, but pays as **"I already did it" (half coins)**. There are no accusations in the UI.

## Screen (`/focus/:taskId`)
| State | Shows | Actions |
|---|---|---|
| Ready | Large crop (seed), task name, `30:00` | **Start** (primary), *I already did it* (text link, asks to confirm) |
| Running | The plant grows (seed → sprout at >0%, young at ≥50%), `mm:ss` countdown with tabular digits, progress bar, "Stage 2 of 4" | **Pause**, *Give up* (asks to confirm; the growth so far stays) |
| Paused | Same, plus "Paused" | **Resume**, *Give up* |
| Ripe | The ripe crop with sparkle, "Ready to harvest!" | **Harvest** (primary, returns to the farm), *Back to farm* |
- **Leaving while it runs:** the timer keeps going. Coming back resumes the same session.
- **Reduce Motion:** no growth bounce; the frame changes instantly.
- **Wrong task:** a non-Daily or unknown task id shows "Task not found".

## Farm integration
`FarmService.plants()` now adds today's focus minutes, so a plant shows **sprout** or **young** on the farm while you're mid-session.

## Verification
- Service tests with a fake clock:
  - start, then elapse, then finish ripens the plant
  - pause and resume keep time
  - closing and reopening (a new service instance) resumes the same time
  - giving up keeps the minutes
  - clock moved back flags and pays half
  - a forward jump is capped
  - farm stages reflect the focus minutes
- Widget test: the Ready screen shows Start; tapping it shows the countdown.
