# Step 1.1: Install Flutter & Android tooling

## Goal
Get `flutter doctor` passing for Android development on this PC, with an emulator ready to run Cultiva.

## Starting point (checked 2026-11-14)
- Android Studio is installed, including its bundled JBR (Java runtime) at `C:\Program Files\Android\Android Studio\jbr`.
- Android SDK at `%LOCALAPPDATA%\Android\Sdk` already has:
  - cmdline-tools (latest)
  - platform-tools, build-tools, emulator, NDK, CMake
  - platforms 33–36
  - the android-36 Google Play x86_64 system image
- No emulator (AVD) has been created yet.
- Git is installed. The system JDK is 25 (`JAVA_HOME`); Flutter should use Android Studio's JBR instead.
- Flutter is not installed.

## Plan
1. `git clone` the official Flutter repo, **stable** channel, into `C:\dev\flutter`.
2. Add `C:\dev\flutter\bin` to the user PATH, and set `ANDROID_HOME` to the SDK folder.
3. Run `flutter config --android-sdk <sdk>` and `--jdk-dir <Android Studio jbr>`, so Gradle uses the JBR and not JDK 25.
4. Accept the Android SDK licenses (approved by the founder).
5. Create the AVD `cultiva_pixel` (Pixel 7 profile, android-36 Google Play x86_64).
6. Run `flutter doctor -v`. Android toolchain and devices must pass; Visual Studio and Chrome warnings are fine because we only target Android.

## How we verify it
- `flutter --version` prints the stable version.
- `flutter doctor` shows ✓ for Flutter and the Android toolchain.
- `flutter emulators` lists `cultiva_pixel`, and it boots.
