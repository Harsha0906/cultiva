# Step 1.2: Create the Flutter project

## Goal
Create an empty Cultiva app with the agreed packages and folder structure, under version control and pushed to GitHub.

## Design
- **Location:** the Flutter project lives in `app/` inside the repo. `docs/`, `tools/` and the raw `assets/` work folders stay at the repo root.
- **Project:** `flutter create --org com.cultiva --project-name cultiva --platforms android,ios app`, which gives the app ID `com.cultiva.app`. The iOS folder is created now but not built until later.
- **Architecture:** feature-first layers (flutter-architecture skill):
  ```
  app/lib/
    main.dart                  # bootstrap (ProviderScope)
    app.dart                   # MaterialApp.router + theme
    core/                      # theme tokens, router, utils, constants
    data/                      # drift database, tables, repositories
    domain/                    # pure Dart: day engine, rewards, models (unit-tested)
    features/
      farm/  tasks/  focus/  shop/  progress/  profile/  onboarding/
    game/                      # Flame components (scene, plants, capybara)
  app/assets/
    sprites/  fonts/  sfx/
  ```
- **State:** Riverpod (`flutter_riverpod` + `riverpod_annotation` with code generation). It stays testable and avoids global singletons.
- **Packages:**
  - **Runtime:** flame, flutter_riverpod, riverpod_annotation, go_router, drift, drift_flutter, path_provider, flutter_local_notifications, timezone, fl_chart, google_fonts (fonts get bundled later), intl, uuid
  - **Dev:** build_runner, drift_dev, riverpod_generator, custom_lint, riverpod_lint, flutter_lints
  - Versions come from `flutter pub add`, so each is the latest compatible release.
- **Lint:** `flutter_lints` plus a few strict rules (prefer_const, avoid_print, require_trailing_commas off).
- **Git:**
  - The repo root is `C:\Users\harsh\cultiva`, with a `.gitignore` covering Flutter build output, `.dart_tool`, the Python cache and the art-test reference image.
  - **Excluded from git:** the CraftPix raw packs (they stay on E:\), the third-party reference image, and `.claude/` skill folders. Their licenses are separate, and they are tooling, not the app.
  - Remote: `https://github.com/Harsha0906/cultiva`.

## Plan
1. `flutter create` into `app/`.
2. `flutter pub add` the runtime and dev packages.
3. Create the folder structure with placeholder `README` notes, and configure `analysis_options.yaml`.
4. `flutter analyze` and `flutter test` should be clean.
5. `git init`, add `.gitignore`, commit, add the remote, push.
