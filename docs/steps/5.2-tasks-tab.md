# Step 5.2: Tasks tab

## Goal
A plain list of today's tasks for quick check-off without the farm, plus editing and removing tasks.

## Layout
- **Header:** title "Tasks", today's date, and a **Plant** button (primary).
- **Two sections:** **Daily** `x/6` and **To-do & Habits** `x/6`, each with a small "+ Plant here" link while it has room.
- **Rows:** crop thumbnail (current stage), title (Nunito, wraps to 2 lines), a subtitle, and one action on the right.
  - **Subtitle:** e.g. `30 min · Every day`, `Mon · Wed · Fri`, `To-do`, `Habit · Weekdays`. A status adds `· Dormant` or `· Resting today`.
  - **Action** (always a visible button; no swipe-only actions):
    | Stage | Button |
    |---|---|
    | Daily, unfinished | ▶ **Start** (Focus Mode) |
    | Plot B, unfinished | ✓ **Done** (ripens it) |
    | Ripe | **Harvest** |
    | Harvested | a check mark |
    | Resting | "Rest day" |
- **Empty state:** "Your plots are empty. Plant a task to start growing." plus a Plant button.

## Edit sheet (tap a row)
- **Rename**, change **crop**, change **duration** and **days** (Daily) or **days** (habit).
- **Undo today's completion** when ripe, or **undo the harvest** when harvested.
- **Remove from farm:** asks for confirmation, then archives the task (history is kept). A message offers **Undo**, which restores it to its slot or the next free one.

## Files
`app/lib/features/tasks/tasks_screen.dart`, `app/lib/features/tasks/edit_task_sheet.dart`, and `TaskRepository.update()`

## Verification
Widget tests:

- Done ripens and then Harvest pays coins
- removing asks first, then undo restores the task
- the empty state
