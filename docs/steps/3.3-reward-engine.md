# Step 3.3: Reward engine (pure Dart, test-first)

## Goal
Coins reward **commitment and consistency, not task count**, and padding or faking tasks gains nothing (design spec §4, game-design panel).

## Rules
| Harvest | Coins |
|---|---|
| Timed task, target < 15 min | 5 |
| Timed task, 15–60 min | 12 |
| Timed task, > 60 min | 25 |
| Check task (to-do or habit) | 8 |
| "I already did it" on a timed task (logged without the timer) | 50% of the above, rounded down |
| **Full Basket** bonus: every Plot A task due today harvested (only if at least one was due) | +20, once per farm day |

- **Daily cap:** at most 150 coins per farm day, bonus included. Payout = `min(amount, cap − earned today)`, never negative.
- **Un-harvest (undo):** reverses exactly what that harvest paid, including a Full Basket bonus it triggered.
- **Ledger:** append-only. Every change is a row `(delta, reason, refId, day)` and the balance is the sum. Rows are never edited or deleted, so history can be audited.

## Files
- `app/lib/domain/rewards.dart`: `baseCoins(task, method)`, `RewardCalculator.payout(...)`, `LedgerReason`
- Tests in `app/test/domain/rewards_test.dart` are written first

## Verification
Unit tests cover:
- each tier boundary (14, 15, 60, 61 min)
- manual half rate
- the cap: partial payout at the edge, 0 after the cap
- bonus: triggers once, not with no Daily tasks due, and counts toward the cap
- the undo amount
