# Step 4.2: Live plants on the farm

## Goal
The plots show the player's real tasks, each in its real stage, and they respond to taps.

## Design
- **Data:** a `farmViewProvider` stream re-runs `FarmService` whenever the tasks, completions or ledger tables change (Drift `tableUpdates`). It produces a `FarmView`: day, plants, balance, done/due counts, next-up task and harvest count.
- **Stage → sprite:**
  | Stage | Shown as |
  |---|---|
  | seed | crop frame 0 (mound with seed) |
  | sprout | frame 1 |
  | young | frame 2 |
  | ripe | frame 3, plus the looping 4-frame sparkle |
  | dormant | frame 4 (wilted) |
  | resting | frame 1 at 60% opacity |
  | harvested | frame 0 plus a small coin mark |
  | empty slot | a faint dashed "+" |
- Each planted cell gets a **wooden name stake**.
- **Plot signs:** Flutter labels such as `DAILY 2/6` and `TO-DO & HABITS 1/6`, placed with `FarmLayout`.
- **Taps:**
  | Tap | Action |
  |---|---|
  | Empty soil | "Plant a task" (the sheet arrives in step 5.1; until then a message) |
  | Plot A plant (seed, sprout, young, dormant) | Open Focus Mode (`/focus/:id`) |
  | Plot B plant (pending or dormant) | Complete → ripe |
  | Any ripe plant | Harvest → coins (the fly animation comes in step 5.3) |
  | Resting plant | Message: "Resting today" |
- **Feedback:** a light haptic on complete and harvest, and a short message with the coins earned.
- **Debug seeding:** the `/dev/kit` gallery gets a "Seed demo farm" button, used for screenshots and testing on the emulator.

## Verification
- Unit test: stage → frame mapping.
- Widget test: the Farm screen with a fake scene shows the plot labels and counts from an in-memory database.
- Emulator: a seeded farm shows mixed stages; tapping a to-do ripens it and tapping again harvests it, and the coin pill updates.
