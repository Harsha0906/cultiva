# Step 11.3: Release build

## App icon (decided: a sprout on teal)
- `tools/art/draw_icon.py` draws a **pixel-art sprout in a soil mound** on the brand teal, in Cultiva's own palette.
- **Android adaptive icon:** a background layer (teal with a soft pixel vignette) and a foreground (the sprout, inside the 66 % safe zone), at 432 px for every density, plus a monochrome layer for Android 13 themed icons.
- **Legacy icons:** square `mipmap-*/ic_launcher.png` for older launchers.
- It's easy to swap later if the capybara design becomes the icon.

## Splash
- **Android 12+ splash API:** `windowSplashScreenBackground` = paper `#F8EED6` plus the sprout icon. The pre-12 `launch_background` uses the same colour and a centred sprout.
- No extra package; done in Android resources.

## Versioning
`1.0.0+1` in `pubspec.yaml` (versionName 1.0.0, versionCode 1). Bump the `+N` for every store upload.

## Signing (decided: generated for you)
- **Keystore:** `C:\Users\harsh\.cultiva\upload-keystore.jks`, outside the repo. RSA 2048, valid 10 000 days, alias `upload`.
- **Passwords:** random, stored only in `app/android/key.properties`, which is **git-ignored**.
- **`build.gradle.kts`** reads `key.properties` when it exists. Without it, the release build falls back to debug signing, so CI and other clones still build.
- **⚠️ Back up both the `.jks` file and `key.properties`** (a password manager or offline drive). Without them you can't publish updates under the same Play listing. With Play App Signing, Google holds the app key and this is the *upload* key, which Google can reset, but backing it up saves the hassle.

## Release hardening
- R8 minify and shrink resources are on; keep rules are added only if a plugin breaks in release.
- The `/dev` debug routes are already compiled out (`kDebugMode`).

## Outputs
- `app/build/app/outputs/bundle/release/app-release.aab` (for Play)
- `app/build/app/outputs/flutter-apk/app-release.apk` (for sideloading and testing)

## Verification
- Install the release APK on the emulator and do a smoke run: onboarding → plant → harvest → shop.
- Check the icon on the launcher and the splash screen.
- `apksigner verify --print-certs` shows the upload certificate, not the debug one.
