# Step 3.2: Day engine (pure Dart, test-first)

## Goal
One place decides **which farm day it is, which tasks are due, and what each plant looks like**, with no Flutter or database code, so it can be fully unit-tested.

## Rules
- **Farm day:** a day runs from the reset hour (default **4:00**, set in Settings) to the next reset. At 02:30 on Tue 17 Nov it is still the farm day **Mon 16 Nov**. Days are stored as `YYYY-MM-DD`.
- **Plots and kinds:**
  - **Plot A "Daily":** *timed* tasks (target 1–240 min) that repeat on chosen weekdays (at least one).
  - **Plot B "To-Do & Habits":** *check* tasks. Either a **to-do** (one-off, no repeat days) or a **habit** (repeats on chosen weekdays).
- **Due today:**
  - A repeating task is due when today's weekday is in its repeat set.
  - A to-do is due every day from creation until it's harvested, then it leaves the plot.
- **Capacity:** at most **6 active tasks per plot**, each in slot 0–5.
  - Planting takes the lowest free slot.
  - A harvested to-do frees its slot.
  - Archived tasks free their slot.
- **Plant stage for a task on a given day:**
  | Stage | When |
  |---|---|
  | `resting` | A repeating task that isn't due today (shown as a small sprout, no interaction) |
  | `seed` | Due, no progress yet, not dormant |
  | `sprout` | Timed task with progress > 0 and < 50% |
  | `young` | Timed task ≥ 50%, or a pending check task |
  | `ripe` | Completed today, not yet harvested |
  | `harvested` | Harvested today (daily plants replant as a seed tomorrow) |
  | `dormant` | Missed: see below. **Never dies**; any progress or completion today revives it |
- **Dormant:**
  - **Repeating task:** its previous due day (looking back up to 7 days, and never before the task was created) passed without a harvest, and there's no progress today.
  - **To-do:** created on an earlier farm day and still not done.
- **Revive:** progress > 0 or completed today means the plant is not dormant.

## Files
- `app/lib/domain/farm_day.dart`: `FarmDay` value type with `farmDayOf()`, comparisons, `addDays` and `weekday`
- `app/lib/domain/task.dart`: `PlotKind`, `TaskKind`, `Weekdays` bitmask, `FarmTask`
- `app/lib/domain/plant_engine.dart`: `isDue`, `stageFor`, `freeSlot`, `previousDueDay`
- Tests in `app/test/domain/` are written **before** the code (TDD)

## Verification
Unit tests cover:
- the reset-hour boundaries (03:59, 04:00, around midnight, a custom hour)
- weekday masks
- every stage path, including dormant → revived
- a to-do carrying over
- capacity: the 7th plant is refused
- freed slots getting reused
