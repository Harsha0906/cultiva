# Step 7.1: Shop

## Goal
Coins earned from real tasks buy cosmetic decorations for the farm. No real money in v1, and nothing that speeds up progress.

## Catalogue (`domain/shop.dart`)
12 CraftPix props that fit a decoration spot (36 px wide or less). Each one can be owned once.

| Item | Price |
|---|---|
| Little mushroom | 30 |
| Log seat | 35 |
| Mushroom patch | 45 |
| Round bush | 50 |
| Old stump | 50 |
| Crates | 70 |
| Evergreen shrub | 70 |
| Mossy rock | 80 |
| Mini pine | 90 |
| Giant toadstool | 110 |
| Apple bush | 130 |
| Wishing well | 200 |

With a typical 50–150 coins a day, that's a new decoration every 1–3 days.

## Rules (`data/shop_service.dart`)
- **Buy:**
  - Runs in one transaction.
  - Fails if the item is already owned ("You already have this") or the balance is too low ("Need N more coins").
  - Writes an inventory row plus a ledger row (`purchase`, −price, refId = item id).
- **Purchases never touch the daily earning cap.** The cap only counts harvest, bonus and unharvest rows.

## Screen (Shop tab)
- **Header:** "General Store" with the live coin balance.
- **Grid of item cards:** the sprite at 3×, name, price with a coin icon, then one of:
  - **Buy** (teal)
  - **Owned ✓**
  - "Need N more" (disabled, with the text explaining why)
- **Buy flow:** a confirm sheet, "Buy Wishing well for 200 coins?", with **Buy** or **Cancel**. Its submit guard blocks double spending. On success it offers **Place it now**, which opens the spot picker from step 7.2.

## Verification
- Service tests:
  - a buy deducts from the balance
  - too few coins is refused and changes nothing
  - an owned item is refused
  - a purchase leaves `earnedOn` unchanged
- Widget test: the shop shows Buy, Owned and Need-more states.
